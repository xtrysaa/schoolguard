# DESIGN.md — SchoolGuard (сайт и программа)

## На что опирается
Просмотрены три сайта из той же области (компьютерное зрение и физическая безопасность), 11.11.2026:

| Сайт | Что взято | Что не взято |
|---|---|---|
| roboflow.com | тёплая светлая «бумага» и тёмные полосы по очереди; мелкие кнопки моноширинным прописным шрифтом; радиус 4 px; настоящее видео продукта на первом экране; сетка из волосяных линий | фиолетовый акцент, логотипы клиентов (у нас их нет) |
| verkada.com | тёмно-синий «ночной» цвет вместо чёрного; крупные заголовки весом 600; большие блоки с изображением продукта | кнопки-пилюли, карусели |
| tractian.com | плавающие карточки с живыми числами поверх изображения; очередь событий с числом и статусом; сетка-подложка; синий акцент; радиус 2–4 px | изометрические схемы, блоки про выручку |

Общее у всех трёх: один акцентный цвет, чередование светлых и тёмных полос, главное изображение — сам продукт с данными.
Наблюдения сделаны по главным страницам; пользователей никто не опрашивал, юзабилити-тестов не было.

## Направление
**Светлая страница с тёмно-синими полосами там, где работает продукт.** Сайт объясняет и убеждает (светлый фон, много текста),
программа — рабочее место оператора (тёмная, плотная, с числами). Их связывают одни и те же цвета, шрифты данных и элементы:
число риска, шкала с порогом, карточка события.

Чего нет намеренно: цветных градиентов, свечения, стекла, эмодзи вместо иконок, выдуманных отзывов и логотипов,
трёх одинаковых карточек с иконками, анимаций без смысла. Движение на странице только одно: настоящая запись со скелетами
и числами, которые посчитала система.

Правила: акцент — только для действий. Состояния — только зелёный, янтарный, красный, и всегда с подписью словом
(цвет не единственный носитель смысла). Белый текст на акцентной кнопке: контраст 5,6:1.

## Типографика
- **Golos Text** (400/500/600/700) — текст и заголовки сайта. Заголовки: 600, трекинг −0.04em, `text-wrap: balance`.
- **JetBrains Mono** (400/500) — данные: числа, время, номера камер, подписи разделов, мелкие кнопки (прописные, трекинг 0.06–0.1em).
- Шкала сайта: 12 / 13 / 15 / 17 / 22 / 40 / 58. Текст 17 px, межстрочный 1.55, строка до 70 знаков.
- В программе системные шрифты (Segoe UI Variable, Cascadia Mono): она работает без интернета. Текст 14 px, числа риска 38 px.

## Сетка и форма
- Сайт: контейнер 1160 px, поля 24 px; заголовок секции — левая колонка 200 px с номером, справа заголовок. Отступ секций 84 px.
- Шаг 4/8. Радиус 4 px (кнопки, поля), 6 px (панели, кадры), 8 px (крупные блоки). Тени только у плавающих карточек первого экрана.
- Сетка 64 px из волосяных линий — фон первого экрана.

## Состояния
- Камера: в сети / подключение / нет сигнала / выключена — точка + текст.
- Риск: спокойно / риск растёт / тревога — цвет числа, шкалы, рамки плитки и слово рядом.
- Пусто: «Камер пока нет» с двумя действиями; «Тревог пока не было» в очереди.
- Ошибки: текст под полем красным, без всплывающих окон; сбой связи с Telegram — строкой в разделе Telegram.

## Доступность: что сделано и что не проверено
- Сделано: контраст текста посчитан по парам из таблицы; видимый фокус у кнопок, полей, пунктов меню; состояния продублированы словами;
  `prefers-reduced-motion` отключает плавную прокрутку; у видео на сайте нет звука и есть кнопка паузы.
- Не проверено: программа чтения с экрана, полный проход с клавиатуры, масштаб 200 %, ширина телефона после смены темы.
  Заявлять соответствие WCAG по этому нельзя.
