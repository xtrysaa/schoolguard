# SchoolGuard

Система раннего предупреждения о драках и физической травле в школе. Программа для Windows подключается к камерам,
следит за движениями людей (скелеты, а не лица) и при признаках конфликта отправляет психологу в Telegram
видеозапись момента: номер камеры, дата, время. Решение всегда принимает человек.

- Сайт с демо: https://schoolguard-roan.vercel.app
- Программа: [SchoolGuard.exe](https://github.com/xtrysaa/schoolguard/releases/latest/download/SchoolGuard.exe) (Windows 10/11, установка не нужна)

## Как пользоваться программой

1. Запустите `SchoolGuard.exe`. Откроется окно программы (интерфейс работает локально, на `127.0.0.1`).
2. **Камеры → Добавить камеру.** Для IP-камеры выберите производителя, введите IP-адрес, логин и пароль: ссылку RTSP
   программа составит сама. Можно подключить веб-камеру или видеофайл. Кнопка «Проверить подключение» покажет кадр.
   Без камер работу видно на встроенной демо-записи («Показать на демо-записи»).
3. **Telegram.** Один раз создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и вставьте его токен.
   Затем «Подключить получателя»: наведите телефон на QR-код и нажмите «Старт» — или отправьте боту шесть цифр кода.
   Идентификаторы чатов вводить не нужно. Получателей может быть несколько.
4. При тревоге в Telegram приходит видео (5 с до события и 5 с после) с подписью: номер и название камеры, дата, время,
   риск, признаки. Кнопки «Подтвердить» и «Ложная тревога» записывают отметку в журнал «События».
5. **Настройки:** чувствительность (три режима с порогами, подобранными на проверочных данных), закрытие лиц,
   длина записи, срок хранения, запуск вместе с Windows.

Записи и настройки хранятся в `%LOCALAPPDATA%\SchoolGuard`. Наружу уходят только клипы тревог — в Telegram.

## Как это устроено

```
камера → YOLO11s-Pose (ONNX) → трекер ByteTrack → 31 признак кадра → окно 2 с → градиентный бустинг → риск
                                                                         тревога при риске ≥ порога 0,8 с подряд → клип → Telegram
```

| Часть | Файл | Что делает |
|---|---|---|
| Детектор поз | `schoolguard/pose.py` | YOLO11s-Pose в ONNX Runtime (DirectML: любая видеокарта, иначе процессор) |
| Трекер | `schoolguard/tracker.py` | своя реализация схемы ByteTrack (двухэтапное сопоставление по IoU), время в секундах |
| Признаки | `schoolguard/features.py` | 31 признак: удары, захват, падение, окружение, преследование, энергия движения |
| Модель | `schoolguard/gbm.py` | деревья XGBoost, предсказание на чистом numpy (без xgboost в программе) |
| Решение | `schoolguard/engine.py` | сглаживание, порог, гистерезис, шесть объяснимых сигналов |
| Камеры | `schoolguard/camera.py` | захват с переподключением, кольцевой буфер, запись клипа H.264 |
| Telegram | `schoolguard/telegram.py` | привязка по коду/QR, отправка видео, кнопки подтверждения |
| Интерфейс | `schoolguard/server.py`, `schoolguard/ui/` | локальный сервер и страницы программы |

Обучение и приложение используют один и тот же код от детекций до риска, поэтому то, что измерено на тесте,
и то, что работает в программе, — одно и то же.

## Точность

Проверка на 1244 записях, которые не участвовали в обучении (разбиение по исходному видео, дубликаты склеены).
Всего размечено 4820 записей из трёх открытых наборов. Пороги подобраны на отдельной validation-части.

| Чувствительность | Порог | Замечено драк (recall) | Ложных тревог (FPR) | Precision |
|---|---|---|---|---|
| Высокая | 0,59 | 0,84 | 0,31 | 0,73 |
| Средняя (по умолчанию) | 0,65 | 0,79 | 0,22 | 0,78 |
| Низкая | 0,80 | 0,61 | 0,09 | 0,87 |

ROC-AUC по записям: **0,86** (по окнам 2 с: 0,84). При вдвое меньшей частоте кадров: 0,85.

| Источник (средняя чувствительность) | Записей | Recall | FPR | AUC |
|---|---|---|---|---|
| RLVS | 453 | 0,93 | 0,11 | 0,96 |
| CCTV-Fights (камеры) | 239 | 0,61 | 0,26 | 0,70 |
| CCTV-Fights (телефоны) | 461 | 0,77 | 0,36 | 0,80 |
| Surv | 91 | 0,58 | 0,08 | 0,88 |

Чего система не умеет: словесную травлю и бойкот по видео не распознать; спорт и шумные игры иногда похожи на драку;
данные для обучения — открытые наборы, а не съёмка в школах. Подробности и история проверок — в [AUDIT.md](AUDIT.md).

## Запуск из исходников

```bash
pip install -r requirements.txt
python tools/export_onnx.py        # нужен ultralytics (requirements-dev.txt): создаёт models/onnx/yolo11s-pose.onnx
python -m schoolguard              # программа
python tools/selftest.py           # самопроверка математики без видео
```

## Воспроизведение обучения

```bash
pip install -r requirements-dev.txt
# данные: data/raw/rlvs, data/raw/surv, data/raw/cctv (+ groundtruth.json набора CCTV-Fights)
python tools/extract_dets.py --out data/dets_s --gt путь/к/groundtruth.json   # видео -> детекции поз (.npz), один раз
python tools/train.py                                                         # признаки -> модель -> пороги -> reports/v2_metrics.json
python tools/export_demo.py --set surv --out web/public/replay --n 6          # ролики для сайта (только из теста)
python tools/make_demo.py                                                     # демо-запись программы + проверка ответов на ней
pyinstaller desktop/SchoolGuard.spec --noconfirm                              # dist/SchoolGuard.exe
```

## Структура

- `schoolguard/` — ядро и программа (v2).
- `tools/` — извлечение детекций, обучение, экспорт демо, самопроверка.
- `desktop/` — сборка `.exe`.
- `web/` — сайт (Next.js, Vercel; Root Directory = `web`).
- `research_v1/` — первая версия исследования (Streamlit, RF/BiGRU по 10 признакам) и скрипты аудита; см. `AUDIT.md`.
- `DESIGN.md` — дизайн-система сайта и программы.

## Данные и лицензии

- Fight Detection Surv (Aktı et al., 2019) — MIT; только эти видео показаны на сайте и встроены в программу как демо.
- Real Life Violence Situations (RLVS) и NTU CCTV-Fights — только для исследований; видео не распространяются.
- Веса YOLO11 — Ultralytics (AGPL-3.0). Код проекта — для учебных и исследовательских целей.

## Этика и закон

Система не распознаёт лица и личности, закрывает головы пикселями, хранит записи ограниченный срок и никого не
наказывает: она предупреждает взрослого. Внедрение в школе требует информирования родителей и соблюдения
Закона РК «О персональных данных и их защите».
