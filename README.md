# SchoolGuard — раннее выявление признаков буллинга (Human-in-the-Loop)

Система анализирует видео общественных зон школы и **передаёт педагогу/психологу фрагмент на проверку**.
Она не выносит вердиктов и не наказывает автоматически.

```
видео → YOLO11-Pose + ByteTrack → признаки скелетов (features.py) → окно 30 кадров
      → Risk Score (эвристика + XGBoost/RF) → алерт + клип + таймкод → оператор: Подтвердить / Ложное срабатывание
```

## Установка (Windows, RTX 3050)
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
python selftest.py            # проверка математики признаков (без нейросетей)
```

## Порядок работы
1. **Данные.** Скачайте открытые датасеты (RWF-2000, Fight-Detection-Surv, NTU RGB+D — классы взаимодействий,
   S-VIP Campus) в `data/…`. Метка берётся из имени папки (`Fight` → 1, `NonFight` → 0).
2. **Признаки:** `python feature_extractor.py --dir data/RWF-2000/train` (CSV в `data/features/`).
3. **Обучение:** `python train_classifier.py` → `models/clf.joblib`, метрики и графики в `reports/`.
   Проверка кода без данных: `python train_classifier.py --demo` (синтетика, метрики не для публикации!).
4. **Дашборд:** `streamlit run app.py` — загрузка видео / RTSP / веб-камера, скелеты, график риска,
   карточки алертов. Решения оператора пишутся в `feedback/feedback.csv` (будущий датасет дообучения).

## Модули
| Файл | Назначение |
|---|---|
| `config.py` | пороги, веса, окно, пути |
| `features.py` | дистанции, сближение, махи рук, окружение, преследование, поза дистресса |

| `viz.py`, `app.py` | отрисовка и Streamlit-интерфейс |

## Формула Risk Score
`Risk = (0.35·Phys + 0.25·Enc + 0.15·Purs + 0.17·Dist + 0.08·Face) · A`, где
`A = 0.65 + 0.35·min(k,2)/2`, k — число активных (≥0.4) телесных сигналов; затем сглаживание по окну в 30 кадров.
Если обучен классификатор: `Score = 0.7·P(model) + 0.3·Risk`.
Вес лица минимальный: мимика ≠ внутреннее состояние (L. F. Barrett et al., 2019).

## Право и этика
- Обучение — на открытых датасетах и постановочных сценах с письменного согласия участников (и родителей несовершеннолетних).
- Обработка обезличена: ID треков и скелеты; головы пикселизуются, кропы лиц на диск не сохраняются.
- Опора: Закон РК «О персональных данных и их защите» (2013), защита прав ребёнка. Face ID — только как
  описанный модуль масштабирования, в MVP не используется.
- Пороги `T_HIGH/T_LOW` нужно калибровать на реальных данных; значения по умолчанию — стартовые.

## Известные ограничения
- В дашборде кнопки верификации активны после остановки/окончания обработки (особенность Streamlit: клик перезапускает скрипт).
- Нормировка на «рост» неточна при сильном наклоне камеры; ID-switch трекера даёт всплески скоростей (клиппинг в `features.py`).
