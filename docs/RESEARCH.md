# Исследование: лучшие методы и датасеты для детекции насилия

Основа: отчёт OSINT от 2026-11-10 плюс проверка источников. Все цифры взяты из статей и **не сопоставимы напрямую**: у работ разные разбиения и метрики.

## Методы (что подходит нашей задаче)
| Подход | Результат в литературе | Вывод для проекта |
|---|---|---|
| Видео-трансформеры (CUE-Net, Video Swin) | RWF-2000 ≈ 94 %, RLVS ≈ 99,5 % ([arXiv:2404.18952](https://arxiv.org/abs/2404.18952)) | Точнее всех, но тяжёлые и нужен видеопоток целиком, не подходят для анонимного скелетного пайплайна и слабого GPU |
| Позы + изменения кадра, ConvLSTM (Garcia-Cobo, San Miguel, 2023) | RWF-2000 90,25 % при 60 тыс. параметров ([код](https://github.com/atmguille/Violence-Detection-With-Human-Skeletons)) | Самый близкий по идее к нашему проекту: лёгкая модель на скелетах |
| ST-GCN + трекинг для кампуса (2024) | RWF-2000 87,75 % | Подтверждает схему «трекинг + скелеты» |
| Графы на скелетах (MSA-STGCN, ESTS-GCN) | до 95 % на отфильтрованном NTU RGB+D | Хорошо на лабораторных данных, хуже на камерах |
| PoseC3D (Duan и др., CVPR 2022) | SOTA на 5 из 6 скелетных бенчмарков, устойчив к шуму позы и многолюдным сценам ([arXiv:2104.13586](https://arxiv.org/abs/2104.13586), код pyskl) | Главный кандидат следующего шага: нужны сохранённые ключевые точки |
| «Умеренное» насилие (толчки) на YOLO11-Pose + RF ([arXiv:2605.02659](https://arxiv.org/abs/2605.02659)) | precision 0,98 при фронтальном виде, 0,72 при крутом ракурсе | Прямое подтверждение нашего стека и ограничения по ракурсу камеры |

| Датасет | Размер / тип | Доступ | Статус в проекте |
|---|---|---|---|
| Fight Detection Surv | 300 клипов, камеры наблюдения, MIT | открыт | **используется** |
| RLVS | 2000 клипов | Kaggle, регистрация, только исследования | **используется** |
| RWF-2000 | 2000 клипов, реальные камеры | подписанное соглашение по почте | запрос отправлен |
| NTU CCTV-Fights | 1000 видео (280 с настоящих CCTV), разметка начала и конца драки | регистрация и заявка, академ. использование, производные наборы запрещены | нужна заявка пользователя: https://rose1.ntu.edu.sg/dataset/cctvFights/ |
| UBI-Fights | 1000 видео, 80 ч, покадровая разметка (216 с дракой) | страница socia-lab.di.ubi.pt | страница не открылась из браузера, проверить вручную |
| XD-Violence | 4754 видео, 217 ч, ≈254 ГБ ([HF-зеркало, MIT](https://huggingface.co/datasets/jherng/xd-violence)) | открыт, очень большой | не используется: объём и киноконтент |
| Simuletic CCTV Aggressive Poses | 103 синтетических кадра с ключевыми точками, CC BY 4.0 | открыт | возможен для проверки позы, мало |

Ограничение: RLVS, RWF-2000 и CCTV-Fights нельзя выкладывать публично, на сайте используются только ролики Surv.

## Что внедрено по итогам
- Временная модель **BiGRU + внимание** по 30-кадровой последовательности признаков (`train_sequence.py`) и ансамбль с Random Forest.
- Тест (разбиение по видео): ансамбль F1 0,801, ROC-AUC 0,875, ложных тревог 20 % против 25,5 % у RF.

## Следующие шаги по приоритету
1. Получить RWF-2000 и подать заявку на CCTV-Fights (оба с настоящих камер: ближе всего к школьному коридору).
2. Сохранять ключевые точки (не только признаки) и обучить скелетную модель в духе PoseC3D / ST-GCN на top-2 треках.
3. Калибровать пороги на данных школы (с согласиями) и дообучать на `feedback.csv`.
